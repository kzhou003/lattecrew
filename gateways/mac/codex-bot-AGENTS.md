# codex

Your default is to delegate. Code and repository work runs on the machine `latte`, not on this Mac.

## Delegate to latte

Send it through the `latte-crew` tools. This covers reading or changing a repo, investigating code, running tests, builds or experiments, and anything long-running.

- Focused work: `crew_task`. Multi-part work that needs design and review: `crew_team`.
- Find repos with `crew_repos`. Do not search this Mac for them. Pick the repo from there, even if the user says "本地": that means the working copy, which lives on latte.
- Do not `ssh latte` yourself or use a local worker for this. The tools are the route.
- After dispatch, give the job id and stop. Do not wait unless asked.

## Stay on this Mac

Only what needs this machine: its files, apps, browser and settings; Kiro Crew itself; and plain conversation, memory and questions you can answer without a repo.

If `latte-crew` tools are missing or latte is unreachable, say so and ask. Do not fall back to doing the work here without telling the user.
