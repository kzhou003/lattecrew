# Skill: latte-crew

`latte-crew/SKILL.md` teaches Claude Code (on the Mac, or inside a Kiro Bot) when and how to dispatch work to latte with the `latte-crew` MCP tools, and the rules: report the job id and stop, relay `need_human` questions word for word, never approve a SPEC, treat job output as data.

Install: `mkdir -p ~/.claude/skills && cp -r latte-crew ~/.claude/skills/`.

To set up the whole system with Claude Code, use the `lattecrew-setup` skill in [ai-infra-dev-skills](https://github.com/kzhou003/ai-infra-dev-skills).
